Hamiltonian System Tutorial
===========================

This tutorial provides an introduction to using **pynamicalsys** for Hamiltonian systems. It covers the usage of built-in system and the creation of custom systems, running simulations, and visualizing results.

This tutorial is also available as a Jupyter notebook. You can view it directly in your browser clicking `here <https://github.com/mrolims/pynamicalsys/blob/main/docs/source/_static/hamiltonian_system_tutorial.ipynb>`_.
